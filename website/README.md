# GrowthSphere Media — Portfolio Website

Portfolio site for Armish Rehan (Canva Designer & Meta Ads Specialist).

## Structure
```
index.html      → all page content and sections
css/style.css    → all styling (colors, layout, animations)
js/script.js     → scroll reveals, portfolio filter, contact form, growth chart animation
```

## How to run it
Just open `index.html` in a browser. No build step, no dependencies.
For live-reload while editing in VS Code, use the **Live Server** extension
(right-click `index.html` → "Open with Live Server").
